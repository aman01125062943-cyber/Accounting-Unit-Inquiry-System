# منظومة الوحدة الحسابية للاستعلام
### Central Accounting Unit Inquiry System (CBE Inward & Financial Inquiry)

منظومة مركزية مخصصة للوحدة الحسابية، تهدف أساساً إلى **سحب وارد البنك المركزي (CBE Inward)** عبر الربط المباشر مع بوابة HiaaPay، وتوفير **محرك استعلام مالي وبحث فوري** لموظفي الإدارة، مع دعم العمل كخادم شبكة محلية (LAN) متعدد المستخدمين.

---

## 🎯 الوظائف والمهام الأساسية

### 1. سحب وارد البنك المركزي (CBE Inward)
- **الربط المباشر والتلقائي:** وسيط مدمج (Direct Bridge Proxy) للاتصال ببوابة HiaaPay وسحب كشوفات وملفات ودفعات الوارد البنكي لحظياً.
- **إدارة الدفعات والمعاملات:** استعراض تفاصيل الدفعات، أرقام الحسابات، مبالغ العمليات، وحالات التسوية.
- **التخزين والمزامنة المركزية:** حفظ بيانات الوارد في قاعدة بيانات مركزية مشتركة ومزامنتها محلياً لتسريع الاستعلام.

### 2. محرك الاستعلام المالي الشامل
- **بحث فوري ومتعدد المحددات:** استعلام سريع بالرقم القومي (14 رقم)، اسم المستفيد، أو رقم الحساب البنكي.
- **كشف الحساب والعمليات:** عرض تاريخ كافة العمليات والحركات المالية والوارد والمرتد الخاص بالموظف/المستفيد.
- **المطابقة الآلية:** مقارنة معاملات الوارد مع سجلات الصرف وتحديد العمليات المتطابقة وغير المتطابقة.

### 3. العمل عبر الشبكة المحلية (Multi-User LAN Server)
- **خادم مركزي موحد:** يتيح تشغيل المنظومة على جهاز خادم وفتحها من أي جهاز حاسب آلي داخل الشبكة المحلية للوحدة الحسابية دون الحاجة لتثبيت أي برامج على أجهزة المستخدمين.
- **قاعدة بيانات واحدة مشتركة (`hk.db`):** كافة عمليات السحب، التعديل، والاستعلام تُسجل وتنعكس فورياً لدى جميع المستخدمين.

---

## 🏛️ البنية التقنية (Architecture)

- **الخادم الرئيسي (Backend):** .NET 8 (C#) عالي الأداء مبني على محرك Kestrel.
- **وسيط سحب البنك المركزي (Proxy Bridge):** خادم وسيط Node.js يعمل على المنفذ `5002` لتأمين الربط المباشر مع API بوابة HiaaPay وتخطي قيود المتصفح.
- **قاعدة البيانات:** SQLite محلية مركزية عالية السرعة (`hk.db`) تدعم التزامن والاستعلام السريع.
- **واجهة المستخدم (Frontend):** واجهة ويب تفاعلية سريعة (HTML5 / CSS3 / Vanilla JS) تدعم التخزين المؤقت IndexedDB والعمل بسلاسة تامة.

## 🚀 روابط وطريقة التشغيل

### الروابط الافتراضية
- **الدخول من الجهاز الرئيسي (محلياً):**  
  `http://127.0.0.1:5001/`
- **الدخول من أي جهاز آخر في الشبكة المحلية:**  
  `http://<SERVER-IP>:5001/` (مثال: `http://192.168.137.174:5001/`)

### ملفات التحكم المباشرة
- `تشغيل_المنظومة.cmd`: يقوم بفحص المنافذ وتشغيل وسيط سحب الوارد وخادم المنظومة تلقائياً وفتح المتصفح مباشرة.
- `إيقاف_المنظومة.cmd`: يقوم بإغلاق كافة خدمات المنظومة والوسيط بضغطة واحدة وبشكل آمن.
