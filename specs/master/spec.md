# ميزة إدارة الفلاتر في صفحة الإعدادات

## 1. Overview/Context
تتيح هذه الميزة للمستخدم إدارة فلاتر مخصصة (إضافة، تعديل، حذف) تُستخدم لاحقاً لتصفية جداول البيانات (المرتدات). يتم الوصول للميزة من تبويب "إدارة الفلاتر" داخل صفحة الإعدادات.

## 2. Functional Requirements
- يجب عرض زر "إضافة فلتر" لفتح واجهة الإدخال.
- يجب عرض جدول يحتوي على الفلاتر الحالية مع إمكانية (تعديل، حذف) لكل فلتر.
- تدعم واجهة الإدخال حقلاً لاسم الفلتر، وحقلاً لنوع الفلتر (قائمة قيم، أو نطاق رقمي).
- إذا كان نوع الفلتر "قائمة قيم"، يجب عرض حقل إدخال نصوص مفصولة بفاصلة، وزر لاستيراد القيم من العمود الأول لملف Excel.
- إذا كان نوع الفلتر "نطاق رقمي"، يجب عرض حقول لإدخال الحد الأدنى والحد الأقصى (Min / Max).
- يجب حفظ هذه الفلاتر لتكون متاحة في صفحة عرض البيانات الرئيسية.

## 3. Invalid / Edge Cases
- محاولة حفظ فلتر بدون اسم أو بدون قيم معرّفة بناءً على نوعه.
- استيراد ملف Excel غير صالح أو فارغ.
- حذف فلتر غير موجود أو حدوث خطأ أثناء الحذف.

## 4. Technical Constraints & Data Model
- الفلتر يحتوي على: Name (نص), Type (list/range), Values (نص مفصول بفاصلة), Min (رقم), Max (رقم).
- التخزين يجب أن يتم في قاعدة البيانات (Server-side) بدلاً من LocalStorage لضمان بقاء البيانات ومزامنتها لكل مستخدم.
