# قائمة التحقق لمتطلبات نظام الاضابير (Archives System)

**الغرض**: التحقق من جودة ووضوح واكتمال متطلبات ميزة "الاضابير" قبل البدء في التنفيذ التقني.
**تاريخ التحديث**: 2026-04-26 (بعد جلسة التوضيحات)

## اكتمال المتطلبات (Requirement Completeness)
- [x] CHK001 - تم تحديد الأقسام (مرتدات الحوافز حالياً).
- [x] CHK002 - تم تحديد تصميم "عرض التفاصيل" (نافذة Modal مع بحث).
- [x] CHK003 - لا يوجد حد أقصى (تجميع في Batch).
- [x] CHK004 - الصلاحيات للمدير العام فقط.

## وضوح المتطلبات (Requirement Clarity)
- [x] CHK005 - الفلتر يعتمد على نطاق تاريخي يختاره المستخدم.
- [x] CHK006 - التنسيق ISO-8601 للتخزين ولحظي للعرض.
- [x] CHK007 - القسم الأصلي مخزن في `SourceTable`.

## اتساق المتطلبات (Requirement Consistency)
- [x] CHK008 - يتوافق مع سياسة النظام (حذف بعد الأرشفة مع إمكانية الاستعادة).
- [x] CHK009 - التصميم يتبع معايير النظام الحالية.

## تغطية الحالات والسيناريوهات (Scenario Coverage)
- [x] CHK010 - تم معالجة التكرار برمجياً.
- [x] CHK011 - رسالة تنبيه عند نقص السبب (5 أحرف).
- [x] CHK012 - الاستعادة تعيد السجلات للأصل وتحذف الـ Batch.

## قابلية القياس والتحقق (Measurability)
- [x] CHK013 - التصدير يعتمد على المكتبات الحالية المجرّبة.
- [x] CHK014 - البحث يعمل جزئياً وشاملاً.
