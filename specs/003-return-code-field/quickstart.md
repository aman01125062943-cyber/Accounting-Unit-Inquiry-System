# Quickstart: حقل كود المرتد

## كيفية التحقق من الميزة

1. **تشغيل النظام**: قم ببناء وتشغيل السيرفر.
2. **فحص قاعدة البيانات**: تأكد من وجود عمود `ReturnCode` وأنه يحتوي على بيانات.
3. **البحث**: ابحث باستخدام الرقم الأوسط (مثلاً `8001012600529`).
4. **الفلترة**: استخدم فلتر النطاق وتأكد من استجابته للأرقام فقط.

## الأوامر المفيدة
- `dotnet run` (لتشغيل السيرفر).
- `Invoke-WebRequest -Uri "http://localhost:5001/returns?search=8001012600529"` (لاختبار البحث برمجياً).
