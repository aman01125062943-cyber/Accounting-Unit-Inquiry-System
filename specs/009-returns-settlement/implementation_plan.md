# خطة التنفيذ: سداد المرتدات (009-returns-settlement)

## 1. Technical Context
- **الهدف:** توفير واجهة وقدرات برمجية لرفع ملف Excel يطابق السجلات لتسديد المرتدات آلياً.
- **NEEDS CLARIFICATION:** لا يوجد (طريقة عرض الجدول والملخص واضحة، المطابقة محددة بالاسم أو الرقم القومي، والحماية من التحديث الخاطئ محددة بشرط فراغ حقل تاريخ الاعتماد).

## 2. Phase 0: Outline & Research
- **Decision:** إضافة قسم جديد في واجهة `index.html` يمكن الوصول إليه عبر زر بالقائمة (مثلاً: سداد المرتدات). 
- **Rationale:** للفصل المنطقي بين لوحة القيادة، الحوافز، والآن سداد المرتدات بملف خارجي.
- **Alternatives considered:** نافذة منبثقة (Modal) ولكن قسم منفصل يوفر مساحة أفضل لعرض الملخص والجدول إن لزم الأمر.

## 3. Phase 1: Design & Contracts

### 3.1 الواجهة الأمامية (`index.html`)
- [ ] إضافة زر `السداد` أو `سداد المرتدات` في القائمة الجانبية (Sidebar).
- [ ] إضافة كتلة `#page-settlement` تحتوي على:
  - زر إدخال ملف (File Input) يدعم `.xlsx`.
  - خيارات راديو لاختيار طريقة المطابقة (بالاسم أو الرقم القومي).
  - مساحات لعرض: (إجمالي الصفوف، السجلات المطابقة، السجلات غير المطابقة/المتجاهلة).
  - زر `تنفيذ السداد` معطل مبدئياً ويتفعل إذا كانت السجلات المطابقة > 0.

### 3.2 منطق التشغيل (`app.js`)
- [ ] دعم التنقل (Routing) لصفحة `#page-settlement` داخل الدالة `navigateTo`.
- [ ] دالة قراءة وتجهيز الملف `handleSettlementFile(file)` وفلترته.
- [ ] دالة المطابقة `matchSettlementRecords(importedData, matchType)` والتي:
  - تتأكد أن سجل قاعدة البيانات لا يحتوى على قيمة في حقله `تاريخ اعتماد المرتدات`.
  - تُطابق باستخدام الاسم أو الرقم القومي.
- [ ] دالة عرض الملخص وتوفير البيانات للمرحلة النهائية.
- [ ] دالة تنفيذ السداد `executeSettlement(matchedRecords)` التي تُحدّث السجلات وتضيف قيم: (تاريخ الاعتماد، التعديل وغيرها) وتقوم بحفظ التحديث وعرض الرسالة.
