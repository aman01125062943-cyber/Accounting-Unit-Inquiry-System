# دستور المشروع لاستخدام الإيجنت

1. أي طلب تعديل أو حل مشكلة يجب أن يتبع خطوات Spec‑Kit:
   - Specify: وصف المشكلة والحل
   - Plan: وضع خطة التنفيذ
   - Tasks: تقسيم المهمة
   - Implement: تنفيذ التعديل

2. يجب على الإيجنت استخدام **المهارات المثبتة مسبقًا** (مثل "حل_المشاكل_الاحترافية") لكل مهمة.

3. أي رد من الإيجنت يجب أن يكون **مختصرًا وواضحًا بالعربي**.

4. إذا اكتشف الإيجنت أن هناك مشكلة أو نقص في المهارات:
   - يقترح **إنشاء مهارة جديدة** لتغطية هذا النقص.
   - لا يطبق أي تعديل خارج نطاق المشكلة أو بدون مهارة مناسبة.

5. أي تعديل أو إصلاح يجب أن يكون ضمن نطاق المشكلة فقط ولا يمس أي كود أو بيانات خارج النطاق.
