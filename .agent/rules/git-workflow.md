# Git Workflow Rules

1. **الالتزام بالتحديث**: يجب عرض تحديث Git بعد كل خطوة برمجية ناجحة أو تغيير جوهري في الملفات.
2. **طلب الإذن**: لا يتم تنفيذ `git commit` أو `git push` تلقائياً دون سؤال المستخدم أولاً والحصول على موافقته الصريحة.
3. **صيغة الرسائل**: يجب أن تكون رسائل الـ `commit` واضحة وتصف التغيير باللغة العربية أو الإنجليزية حسب سياق المهمة.
4. **التحقق**: قبل التحديث، يجب التأكد من عدم وجود أخطاء برمجية واضحة (Syntax errors).
