# مهارة Chrome DevTools MCP

تسمح هذه المهارة للوكيل الذكي بالتحكم في متصفح Chrome وفحص العناصر واختبار الاستجابة.

## كيفية الاستخدام
1. استخدام أداة `browser_subagent` لتنفيذ مهام فحص الواجهة.
2. التركيز على التنبيهات (Toasts) ونوافذ الحوار (Dialogs) الجديدة.
3. التحقق من أن العناصر لا تحجب التفاعل مع الصفحة.

## مهام الاختبار المطلوبة
- فحص موقع التنبيهات في أعلى اليمين.
- التأكد من أن `pointer-events: none` يعمل في نافذة الحوار Lite.
- فحص سرعة استجابة الأنيميشن.
