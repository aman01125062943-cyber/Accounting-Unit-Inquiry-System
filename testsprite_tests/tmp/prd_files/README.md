# مشروع HK - نسخة C# (.NET 8.0)

تم إعادة بناء المشروع باستخدام تقنيات مايكروسوفت ليتوافق مع جهازك.

## المكونات الأساسية:
- **Backend**: ASP.NET Core (.NET 8.0)
- **Frontend**: HTML5/CSS3 (Modern Design)
- **API**: مدمج داخل السيرفر لتجهيز البيانات.

## طريقة التشغيل:
1. اذهب لمجلد المشروع `hk`.
2. اضغط مرتين على ملف `run_server.bat`.
3. سيفتح السيرفر محلياً (غالباً على http://localhost:5000 أو 5291 - سيظهر العنوان في الشاشة السوداء).

## المميزات:
- استضافة ذاتية بالكامل.
- مسارات صحيحة (Routing) تدعم الـ API وصفحة الـ 404.
- واجهة احترافية تدعم اللغة العربية.
