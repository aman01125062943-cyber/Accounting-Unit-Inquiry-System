الإعدادات العامة

خيارات عامة لا تغيّر قاعدة البيانات أو الصلاحيات.

اتركه فارغاً للاعتماد على الخادم الحالي. استخدم عنوان الخادم المركزي لضمان وصول الإشعارات لكل الأجهزة.

الاستيراد والتسوية التلقائية للملفات

حدد المجلد الرئيسي لمراقبة واستيراد وتدوير ملفات التعلية والسداد تلقائياً.

يمكنك إدخال مسار محلي أو مسار شبكة (UNC) مثل: \\128.30.200.225\esth_share\...

سيتم إنشاء المجلدات الفرعية (حوافز، مرتبات، استيراد، سداد) تلقائياً داخل المسار المحدد أعلاه.

# اسم المستخدم الاسم الكامل الصلاحية الحالة الإجراءات

الأمان والتشغيل

إعدادات حساسة تؤثر على فتح صفحة الإعدادات وتشغيل النظام.

لا تغيّر هذه القيم إلا عند الحاجة. إعدادات NetworkMode أو Dangerous Operations غير معروضة كحقول في هذه الصفحة حاليًا.
يتم حفظ الرمز في إعدادات الخادم.

الصيانة والنسخ الاحتياطي

عمليات صيانة للكاش والفهارس. استخدمها عند الحاجة فقط.

هذه العمليات قد تعيد بناء بيانات المتصفح أو الفهارس، لكنها لا تغيّر أسماء الأعمدة أو منطق الاستيراد.

استخدم هذه الخيارات إذا لاحظت أن البيانات لا تظهر بشكل صحيح بعد التحديثات.

آخر تحديث: - | عدد السجلات المفهرسة: 0

يتم استخدام فهرس خفيف للفلاتر والبحث بدون تحميل السجلات الثقيلة إلى المتصفح.

المرفقات والأرشفة

مسارات الصور وطريقة مطابقة المرفقات بالسجلات.

حدد الطريقة التي سيستخدمها النظام لمطابقة ملفات الصور مع السجلات.

المزامنة التلقائية والماسح

إعدادات تقنية متقدمة موجودة حاليًا في النظام.

إعدادات NAPS2 / Scanner موجودة في الخادم، لكن لا توجد حقول ظاهرة لها داخل صفحة الإعدادات الحالية.
