نسخة HK المحمولة بدون إنترنت
============================

طريقة التشغيل:
1. افتح هذا المجلد على أي جهاز Windows 64-bit.
2. شغل الملف Start_Offline.bat.
3. سيفتح النظام تلقائيا على:
   http://localhost:5001

ملاحظات مهمة:
- النسخة لا تحتاج تثبيت .NET Runtime أو SDK.
- كل مكتبات التشغيل مرفقة داخل المجلد.
- قاعدة البيانات هي الملف hk.db الموجود بجانب HKServer.exe.
- للعمل من أجهزة أخرى على نفس الشبكة، افتح Setup_Firewall.bat كمسؤول مرة واحدة على جهاز السيرفر، ثم افتح:
  http://IP-ADDRESS:5001

نقل النسخة لجهاز آخر:
- انسخ المجلد كاملا كما هو.
- لا تحذف hk.db أو wwwroot أو ملفات dll.
- شغل Start_Offline.bat فقط.
